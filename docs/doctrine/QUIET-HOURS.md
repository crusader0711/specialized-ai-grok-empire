# Quiet hours

Default window: `<QUIET_START>`–`<QUIET_END>` owner local time.
During quiet hours only these break through:
- XREP weather (any watch, advisory, or warning for a registered site)
- XREP health
- Owner-declared breakers (for example P1 earnings flashes)

Everything else queues for the morning brief. Use 24-hour times everywhere.
