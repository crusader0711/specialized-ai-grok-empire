# Theming your team

SAGE ships with plain, role-based names so anyone can fork it. The original team used a
Star Wars-style theme; forks are free to use any theme (or none). Put your themed name in the
`themed_name:` field of each `bots/<id>/PROFILE.md` and in `docs/roster.md`.

| Role | Example theme slot |
|---|---|
| Chief of Staff | <THEMED_NAME_COS> |
| Weather & Hazards | <THEMED_NAME_WEATHER> |
| Kitchen Chef | <THEMED_NAME_KITCHEN> |
| Academic Advisor / Repo Steward | <THEMED_NAME_ACADEMIC> |
| Finance | <THEMED_NAME_FINANCE> |
| Markets | <THEMED_NAME_MARKETS> |
| Home Systems | <THEMED_NAME_HOME> |
| Health & Longevity | <THEMED_NAME_HEALTH> |

Rule: a themed name is cosmetic. Routing, CI, and file paths always use the bot id.
