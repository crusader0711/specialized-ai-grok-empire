# grok-empire-dashboard

Two-page static dashboard for **SPECIALIZED AI GROK EMPIRE** — Project SAGE,
the foundational Grok Bot fleet model. Dark imperial holo-terminal theme on the static-spa v1.TW engine: zero
backend, hash-routed, open `index.html` to preview (no server needed).

**Pages:** Empire (`#/`) — the pitch: numbers, the RED-tier law, doctrine
pillars, artifact ladder, feature grid · Fleet (`#/fleet`) — role-archetype cards (AGENT-01…)
with sigils, duties, and governing rules + reserved seats.

Generic base-model content (fleet metadata only — no doctrine
values, balances, PHI, or credentials). Everything editable lives in
`js/data.js`; theme tokens at the top of `css/style.css`.

Specialized teams fork this and theme agent and room names in `js/data.js`.
Logo and favicon: `docs/assets/logo-web.jpg` (referenced relative to repo root).
