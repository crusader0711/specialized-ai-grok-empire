# Contributing

<!-- DECISION FOR OWNER: contribution policy (open PRs / issues only / maintainers only). -->

1. Open an issue first for new doctrine or new roles.
2. One change per PR. New rules come with an ADR in `docs/decisions/`.
3. Run `make lint test` locally; CI runs the same.
4. Never commit personal data, secrets, real registers, health, finance, school, or network details.
5. Charters must keep frontmatter and the `BOUNDARY RULE` paragraph.
